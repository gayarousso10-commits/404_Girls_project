🔐 CyberVault – מערכת תקשורת בין שרת ללקוח
📌 על הפרויקט

CyberVault היא מערכת תקשורת שנכתבה בשפת Python, המאפשרת העברת הודעות בין לקוח (Client) לשרת (Server) באמצעות TCP Sockets.

במסגרת הפרויקט פיתחנו פרוטוקול תקשורת עצמאי, המאפשר שליחה וקבלה של הודעות בצורה מסודרת, בדיקת תקינות ההודעות וטיפול בשגיאות.

📁 מבנה הפרויקט

הפרויקט מורכב מארבעה קבצים מרכזיים:

קובץ	תפקיד
NetworkServer.py	אחראי על הפעלת השרת, קבלת הודעות, עיבוד פקודות ושליחת תשובות.
NetworkClient.py	אחראי על התחברות לשרת, קבלת פקודות מהמשתמש ושליחתן.
Protocol.py	אחראי על שליחה וקבלה של הודעות באמצעות Socket ועל הוספת כותרת לאורך ההודעה.
ProtocolMessage.py	אחראי על יצירת הודעות, בדיקת תקינותן וקידוד ופענוח שלהן.

🌐 פרוטוקול התקשורת

בפרויקט פיתחנו פרוטוקול תקשורת המבוסס על שיטת Length-Prefix Framing.

כל הודעה מורכבת משני חלקים:

1. כותרת (Header)

גודל של 4 בתים.
מכילה את אורך ההודעה.
משתמשת בסדר בתים Big Endian.

2. גוף ההודעה (Message Body)

מכיל את הפקודה ואת המידע הנוסף.
הפקודה והמידע מופרדים באמצעות התו |.
ההודעות מקודדות באמצעות UTF-8.
הגדרות הפרוטוקול
מאפיין	ערך
סוג תקשורת	TCP
שיטת העברת הודעות	Length-Prefix Framing
גודל הכותרת	4 Bytes
סדר בתים	Big Endian
קידוד	UTF-8
מפריד הודעות	`
גודל הודעה מקסימלי	1MB
💻 הפקודות הנתמכות

השרת תומך בארבע פקודות:

פקודה	תיאור	תשובת השרת
TIME	מחזירה את התאריך והשעה הנוכחיים.	תאריך ושעה
ECHO	מחזירה את הטקסט שנשלח לשרת.	הטקסט שנשלח
PING	בודקת שהתקשורת בין הלקוח לשרת פועלת.	PONG
EXIT	מסיימת את החיבור בין הלקוח לשרת.	BYE

🔄 תהליך התקשורת

תהליך העברת ההודעות בין הלקוח לשרת מתבצע בשלבים הבאים:

המשתמש מקליד פקודה בצד הלקוח.
ProtocolMessage יוצרת הודעה ובודקת את תקינותה.
Protocol.send() מוסיפה כותרת לאורך ההודעה ושולחת אותה.
השרת מקבל את ההודעה באמצעות Protocol.receive().
ההודעה מפוענחת והפקודה נבדקת.
השרת מבצע את הפקודה ומכין תשובה.
התשובה נשלחת בחזרה ללקוח באמצעות הפרוטוקול.
הלקוח מקבל את התשובה ומציג אותה למשתמש.
🛡️ בדיקות תקינות וטיפול בשגיאות

המערכת כוללת מספר בדיקות כדי לוודא שההודעות תקינות:

בדיקת תקינות הפקודות המותרות.
בדיקת סוג הנתונים המתקבלים.
בדיקת תווים מפרידים בהודעות.
בדיקת קידוד ופענוח UTF-8.
הגבלת גודל ההודעות ל-1MB.
זיהוי הודעות שהתקבלו באופן חלקי.
טיפול בניתוק בלתי צפוי של החיבור.
▶️ הוראות הפעלה
שלב 1 – הפעלת השרת

פותחים חלון Terminal ראשון ומריצים:

bash
python NetworkServer.py


השרת יופעל וימתין להתחברות של לקוח.

שלב 2 – הפעלת הלקוח

פותחים חלון Terminal שני ומריצים:

bash
python NetworkClient.py


לאחר ההפעלה, הלקוח יתחבר לשרת ויאפשר למשתמש להקליד פקודות.

שלב 3 – בדיקת התקשורת

לאחר שהלקוח התחבר, ניתן להקליד את הפקודות הבאות:

TIME
EXIT
