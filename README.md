# CyberVault

## על הפרויקט
CyberVault הוא פרויקט המבוסס על תקשורת בין לקוח לשרת (Client-Server) באמצעות פרוטוקול TCP. הפרויקט מאפשר למספר לקוחות להתחבר לשרת במקביל, לשלוח אליו פקודות ולקבל תשובות.

השרת משתמש ב־Multithreading כדי לטפל בכל לקוח בנפרד, וממשק המשתמש נבנה באמצעות Gradio.

## טכנולוגיות וכלים
- Python
- TCP Sockets
- Multithreading
- Gradio
- Pytest

## מבנה הפרויקט

### NetworkServer
אחראית על ניהול השרת וקבלת חיבורים מלקוחות. עבור כל לקוח שמתחבר נוצר ClientHandler נפרד, וכך ניתן לטפל במספר לקוחות במקביל.

### ClientHandler
מטפלת בתקשורת מול לקוח יחיד. כל ClientHandler פועלת ב־Thread נפרד, מקבלת פקודות מהלקוח ומחזירה את התשובות המתאימות.

### NetworkClient
אחראית על יצירת החיבור בין הלקוח לשרת, שליחת בקשות, קבלת תשובות וסגירת החיבור.

### Protocol
אחראית על העברת ההודעות בין הלקוח לשרת באמצעות TCP. המחלקה מטפלת בשליחת הודעות ובקבלתן, כולל מצבים שבהם הודעה מתקבלת בחלקים.

### ProtocolMessage
אחראית על המבנה של הודעות הפרוטוקול. ההודעות כוללות פקודה ונתונים אופציונליים, ומקודדות לפורמט Bytes לצורך העברתן ברשת.

### GradioClientUI
אחראית על ממשק המשתמש באמצעות Gradio. הממשק מאפשר למשתמש להתחבר לשרת, לשלוח פקודות ולקבל תשובות. לכל Session נשמר חיבור עצמאי לשרת.

### ProtocolError
מחלקת שגיאה ייעודית לטיפול בשגיאות הקשורות לפרוטוקול התקשורת.

## פקודות נתמכות
המערכת תומכת בפקודות הבאות:

| פקודה | תיאור |
|---|---|
| PING | בדיקת תקינות התקשורת מול השרת |
| ECHO | החזרת הנתונים שנשלחו לשרת |
| TIME | קבלת השעה מהשרת |
| CLIENTS | הצגת מספר הלקוחות המחוברים |
| EXIT | ניתוק הלקוח מהשרת |

בנוסף, המערכת מטפלת בפקודות לא מוכרות ומחזירה הודעת שגיאה מתאימה.

## בדיקות
הפרויקט כולל בדיקות באמצעות Pytest, שנועדו לבדוק את תקינות התקשורת ואת פעולת המערכת במצבים שונים, ביניהם:

- חיבור של מספר לקוחות במקביל.
- שליחת פקודות וקבלת תשובות.
- ניתוק לקוחות ועדכון מספר הלקוחות המחוברים.
- טיפול בניתוקים פתאומיים.
- טיפול בהודעות ובפקודות לא תקינות.
- בדיקת הפרדה בין Sessions שונים בממשק.
- סגירה והפעלה מחדש של השרת.

## התקנה והרצה

1. יש להתקין Python.
2. יש להתקין את הספריות הנדרשות באמצעות:

   ```bash
   pip install -r requirements.txt
   ```

3. יש להפעיל את השרת.
4. יש להפעיל את ממשק המשתמש ולהתחבר לשרת.
